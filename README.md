# Titanic Data Analysis Project

## Project Overview
An interactive dashboard for analyzing Titanic passenger data.

## Technologies Used
- PostgreSQL
- Python
- Pandas
- Psycopg2
- Streamlit

## Database
Database: titanic_db
Schema: titanic_project

Tables:
1. passengers
2. survival_details
3. travel_details

Total records: 891

## Features
- Passenger survival analysis
- Gender-wise survival analysis
- Passenger class analysis
- Age group analysis
- Fare analysis
- Passenger search
- Interactive filters
- CSV download

## How to Run
1. Activate the virtual environment.
2. Install the required libraries.
3. Set PostgreSQL connection details.
4. Run: streamlit run app.py
